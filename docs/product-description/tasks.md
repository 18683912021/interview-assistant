# AI Interview Copilot — 研发阶段规划

> **核心原则：阶段零不过，不动阶段一。每个阶段有明确验收标准，达标再推进。**
>
> **前端模板：** `workspace/fe/rn-app-shell` 是已配置 Expo 云打包的 RN 壳子，作为模板保留不动。后续所有前端业务开发，从模板复制新项目开始写代码。
>
> **产品形态：纯 App。** 用户用手机进行线上面试（腾讯会议/飞书/视频面试）时，同一台手机同时运行 Copilot，从系统内部音频流采集面试官声音 → ASR 识别 → LLM 实时生成回答 + 自动记录面试内容。一个设备搞定全部，不做电脑版。
> 
> **⚠️ 关键澄清：** 不是麦克风"偷听"环境音。音频来源是系统内部音频流（音频回采/屏幕录制音频通道），而非物理麦克风收音。手机同时跑视频面试 App 和 Copilot，Copilot 从系统层捕获面试官的声音。
>
> **🗂️ 目录约定：** App 开发统一放 `fe-app/` 目录下，当前项目 `fe-app/audio-capture/`。

## 阶段零 · 技术原型验证

**需求描述：** 用户在手机上进行线上面试（腾讯会议/飞书/视频面试）时，同一台手机同时运行 Copilot App → 系统内部音频流采集面试官声音 → 实时转文字 → LLM 生成答案并展示在屏幕上。纯技术验证，不做登录、知识库、UI 美化、延时优化。

### 0.1 — 技术选型

> 状态：LLM/ASR 已定，PoC 骨架完成。0.1.5-INFRA 已跳过（代码放 workspace，不做 CI/CD），其余全部完成。

#### 🎯 选型结论（已确认）

| 组件 | 选型 | 定论 |
|------|------|------|
| **LLM** | **DeepSeek**（V4-Pro/V4-Flash） | boss 拍板。兼容 OpenAI ChatCompletions 接口，`/v1/chat/completions` 直调。旧模型名 2026.7 停用自动指向 V4-Flash。 |
| **ASR + 说话人分离** | **火山引擎豆包语音识别**（bigmodel 实时 + bigmodel_async 文件级） | 双轨采集方案：前端按 mic/system 分轨推流，后端按 source 标记说话人——mic 轨 = 用户，system 轨 = 面试官。不再依赖 ASR 原生 speaker_id，而是靠采集层面的物理分轨。实时 ASR 用 bigmodel WebSocket，文件级转文字用 bigmodel_async。 |

#### 📊 ASR 选型说明

| 厂商 | 实时 WebSocket | 说话人分离方案 | 结论 |
|------|:--:|------|:--:|
| **火山引擎豆包（已选）** | ✅ bigmodel | 双轨物理分轨（前端 mic/system 分轨 → 后端按 source 标记） | ✅ 架构最干净，说话人分离不依赖 ASR API 能力 |
| 腾讯云 | ✅ | 实时说话人分离 API（speaker_id 0/1） | 备选，API 干净但需额外映射逻辑 |
| 讯飞 | ✅ | 大模型版 rtasr_llm 有，标准版不带 | 两套体系，接入体验差 |
| 阿里云 | ✅ | Fun-ASR-Realtime 有，字段不透明 | 文档不友好 |

> **选火山引擎的核心逻辑：** 双轨采集方案从根本上解决了说话人分离问题——mic 就是用户，system 就是面试官，不需要猜 speaker_id。ASR 本身只需要做好识别，不依赖它做说话人区分。实时链路用 bigmodel WebSocket，离线/文件级用 bigmodel_async，一套厂商搞定。

#### FE 任务清单
- [x] 0.1.1-FE：✅ **PoC 骨架完成**。可行性结论：两端均可跑，但有条件。**Android**：`AudioPlaybackCapture`（Android 10+），MediaProjection + AudioRecord 只采音频不录屏幕，但目标 App 可通过 `allowAudioPlaybackCapture="false"` 拒绝（腾讯会议/飞书有此风险），国产 ROM 后台限制更激进。**iOS**：Broadcast Upload Extension（ReplayKit），用户从控制中心手动启动，Extension 丢视频帧只留音频，但状态栏红条指示器无法隐藏。**结论**：技术路径明确，真正的答案在真机上——PoC 骨架已搭好，下一步补 MediaProjection 权限流程后上真机实测。
- [x] 0.1.2-FE：✅ 技术栈已确定：React Native + Expo，壳子模板 `rn-app-shell` 已跑通云打包
