🚀 AI Interview Copilot 核心功能
① 🎤 实时识别（Live Listening）

通过系统内部音频流实时采集线上面试中面试官的语音（问题、代码题等），自动转文字并记录整场面试内容。**音频来源是系统音频回采（非麦克风环境收音），适用于线上面试场景（腾讯会议/飞书/视频面试）。**

② 🤖 AI 秒回答（AI Copilot）

结合上下文，3 秒内生成个性化回答，支持技术面、项目面、HR 面、算法面。

③ 📚 私人知识库（Personal Knowledge Base）

上传简历、JD、项目、GitHub、文档，让 AI 回答更符合你的真实经历。

④ 🧠 AI 面试情报（Interview Intelligence）⭐（核心壁垒）

自动分析公司、岗位、JD，聚合公开信息，预测高频考点，生成个性化面试题与项目追问。
